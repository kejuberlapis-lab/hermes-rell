# Template SEO Audit Checklist

## 1) Technical
- [ ] robots.txt benar
- [ ] sitemap.xml tersedia dan submit
- [ ] halaman penting terindeks
- [ ] canonical benar
- [ ] mobile-friendly
- [ ] Core Web Vitals aman

## 2) On-Page
- [ ] Title tag unik + keyword utama
- [ ] Meta description menarik
- [ ] H1 tunggal, H2/H3 terstruktur
- [ ] URL slug singkat
- [ ] Internal linking relevan
- [ ] Alt text gambar terisi

## 3) Content
- [ ] Search intent sesuai (TOFU/MOFU/BOFU)
- [ ] Topical depth memadai
- [ ] FAQ/Schema bila relevan
- [ ] Konten update terbaru

## 4) Off-Page
- [ ] Backlink berkualitas bertambah
- [ ] Toxic links dipantau
- [ ] Brand mention meningkat
