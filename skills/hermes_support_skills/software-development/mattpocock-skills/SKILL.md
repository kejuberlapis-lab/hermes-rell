# Matt Pocock Engineering & Architecture Skills

Kumpulan panduan engineering modern untuk pemodelan domain, desain arsitektur modular, diagnosis bug terstruktur, dan code review terstandar.

## Prinsip Kerja
1. **Domain Modeling:** Modelkan entitas bisnis dengan tipe data yang ketat dan representasi domain yang tidak ambigu.
2. **Systematic Bug Diagnosis:** 4 fase investigasi bug: Reproduksi $\rightarrow$ Isolasi akar masalah $\rightarrow$ Minimal fix $\rightarrow$ Regression test.
3. **Standardized Code Review:** Evaluasi kode berdasarkan: Correctness, Type Safety, Edge Case Coverage, dan Maintainability.
