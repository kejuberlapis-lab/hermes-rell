# Telkom — Rule Pekerjaan Admin

> Vault baru. Rule kerja admin Telkom. Update sesuai kebutuhan.

## 1. Identitas Pekerjaan
- **Posisi:** Admin
- **Perusahaan:** Telkom
- **Lingkup:** Administrasi & dukungan operasional

## 2. Rule Utama
- [ ] Semua dokumen masuk → catat di log harian
- [ ] Data pelanggan/pelapor → jangan dibagikan ke pihak luar
- [ ] Deadline tugas → selesaikan H-1 sebelum jatuh tempo
- [ ] Laporan harian → kirim sebelum jam 17:00
- [ ] Surat/memo resmi → wajib CC atasan langsung
- [ ] Absen/izin → lapor maksimal jam 08:00

## 3. Alur Kerja
1. Terima tugas → konfirmasi detail (apa, kapan, siapa)
2. Kerjakan → dokumentasikan setiap langkah penting
3. Selesai → laporkan + arsipkan bukti (screenshot/file)
4. Eskalasi → kalau terblokir > 2 jam, laporkan ke atasan

## 4. Arsip & Penamaan File
- Format: `YYYY-MM-DD_jenis-dokumen_deskripsi.ext`
- Contoh: `2026-08-30_laporan_rekap-keluhan-harian.xlsx`
- Folder: per bulan (`2026-08/`, `2026-09/`, dst)
