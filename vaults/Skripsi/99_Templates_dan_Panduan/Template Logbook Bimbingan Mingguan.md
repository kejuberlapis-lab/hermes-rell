# 📝 Template Sesi Bimbingan

Salin blok di bawah ini ke [[Logbook Bimbingan]] setiap kali selesai sesi bimbingan:

```markdown
---

### 🔹 Sesi #[Nomor Sesi]
- **Tanggal:** DD/MM/YYYY (Pukul HH:MM WIB)
- **Dosen Pembimbing:** Pembimbing 1 / Pembimbing 2 / Keduanya
- **Media Pertemuan:** Luring (Ruang Dosen) / Daring (Zoom / GMeet / WA)
- **Fokus Pembahasan:** Bab X / Konsep Metodologi / Hasil Pengujian

#### 📌 Catatan & Masukan Dosen:
1. ...
2. ...
3. ...

#### 🎯 Tugas / Action Items Pekan Ini:
- [ ] Tugas 1...
- [ ] Tugas 2...

#### 📅 Target Bimbingan Berikutnya:
- Tanggal: DD/MM/YYYY
- Materi yang Dibawa: Draft Bab X yang sudah direvisi
```
