# 🎓 Panduan & Checklist Persiapan Sidang Skripsi (Pendadaran Akhir)

---

## 📌 Checklist Dokumen Pendaftaran Sidang
- [ ] Naskah Skripsi Lengkap (Bab 1 s.d. Bab 5) telah di-ACC Dospem 1 & 2.
- [ ] Lembar Persetujuan Sidang / Rekomendasi Ujian Pendadaran.
- [ ] Sertifikat Uji Kemiripan / Plagiarisme (Turnitin < 20%).
- [ ] Sertifikat Kemampuan Bahasa Inggris (TOEFL / IELTS / Tes Kampus).
- [ ] Surat Bebas Tanggungan Perpustakaan & Laboratorium.
- [ ] Bukti Logbook Bimbingan memenuhi jumlah minimal pertemuan (biasanya 8–12x).
- [ ] Naskah Artikel Ilmiah / Jurnal (sesuai regulasi program studi).

---

## 💻 Kesiapan Demo Sistem / Perangkat / Prototype
- [ ] Video rekaman demo sistem cadangan (antisipasi kegagalan jaringan internet / server down saat sidang).
- [ ] Database lokal yang sudah terisi data sampel pengujian riil.
- [ ] Script pengujian atau checkpoint model terbaik yang siap dijalankan live jika diminta penguji.
- [ ] Repository Git sudah bersih, terdokumentasi dengan `README.md` yang rapi.

---

## 👔 Penampilan & Mental Sidang
- [ ] Pakaian formal sesuai aturan prodi (Kemeja putih, dasi, jas almamater/hitam, celana kain hitam, sepatu pantofel).
- [ ] Tidur cukup malam sebelum sidang; hindari begadang membuat slide baru di malam H-1.
- [ ] Latihan intonasi dan eye-contact dengan slide pointer.
