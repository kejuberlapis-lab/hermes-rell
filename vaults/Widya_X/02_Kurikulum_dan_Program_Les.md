## 🎯 2. Silabus Rinci per Pilar Program

### 🤖 PILAR 1: ROBOTIKA TERAPAN (Robotics & Embedded Systems)
* **Level 1 (Junior - SD 3-6):**
  * Pengenalan komponen robotika: Motor, Gear, Chassis, Sensor Ultrasonik, Line Follower.
  * Pemrograman visual blok (*Blockly / Scratch for Robots*).
  * Proyek: Robot Pengikut Garis, Smart Trash Bin Otomatis, Robot Penghindar Rintangan.
* **Level 2 (Intermediate - SMP/SMA):**
  * Pemrograman mikrokontroler C++ / MicroPython dengan Arduino Uno & ESP32.
  * Komunikasi nirkabel (Bluetooth / Wi-Fi IoT Dashboard).
  * Proyek: Smart Home IoT, Robot Arm 4-DOF Gripper, Robot Hexapod.
* **Level 3 (Advanced - SMA / Mahasiswa / Umum):**
  * Robotika Humanoid Lanjut menggunakan **UBTECH Yanshee** (Linux Raspberry Pi).
  * YanAPI Python SDK, Inverse Kinematics gerak kaki & tangan humanoid, Speech Recognition.
  * Pengenalan Robot Operating System (ROS Kinetic/Noetic).

---

### 🧠 PILAR 2: ARTIFICIAL INTELLIGENCE (AI & Data Intelligence)
* **Level 1 (Fundamentals):**
  * Logika berpikir komputasional & Pemrograman Dasar Python.
  * Memahami konsep data: Teks, Gambar, Suara, dan Angka.
  * Teachable Machine: Melatih model AI deteksi gestur tangan dan klasifikasi objek sederhana.
* **Level 2 (Computer Vision & AI Vision):**
  * Library OpenCV: Pengolahan citra digital, deteksi wajah, deteksi mata, dan *color tracking*.
  * YOLO (You Only Look Once): Object Detection realtime pada webcam & kamera robot.
  * MediaPipe: Deteksi pose tubuh (*Skeleton Tracking*) untuk kendali antarmuka AI.
* **Level 3 (Applied Machine Learning & NLP):**
  * Algoritma klasifikasi & regresi terapan (*Scikit-Learn*).
  * Pengenalan LLM API (OpenAI / Gemini / Claude) & perancangan sistem asisten cerdas.

---

### ⚡ PILAR 3: AI AGENTIC & AUTONOMOUS WORKFLOW (The Modern AI Frontier)
* **Fokus Keunggulan Unik Widya.X:**
  * Mempelajari cara merancang **AI Agent** yang tidak hanya menjawab obrolan pasif, melainkan mampu **menjalankan alat nyata (*tool use*), mengeksekusi kode, mencari web, dan menyelesaikan pekerjaan mandiri**.
* **Materi Kurikulum:**
  1. **Dasar AI Agentic:** Perbedaan Chatbot biasa vs AI Agent (Reasoning, Memory, Tool Calling).
  2. **Multi-Agent Systems:** Mengorkestrasi kolaborasi beberapa agent (Agent Peneliti, Agent Coder, Agent Reviewer).
  3. **Hermes Architecture & Function Calling:** Menghubungkan LLM ke API eksternal, webhook database, dan gateway komunikasi (Telegram/WhatsApp).
  4. **Proyek Akhir:** Membangun *Autonomous Customer Service Agent*, *Automated Research Assistant*, atau *Robotic AI Controller*.

---

### 🛸 PILAR 4: DRONE ENGINEERING & AVIONICS (UAV & FPV)
* **Level 1 (Aviation Basics & Flight Safety):**
  * Teori aerodinamika (Thrust, Lift, Drag, Gravity) dan anatomi quadcopter.
  * Protokol keselamatan penerbangan (*Aviation Safety & Regulations*).
  * Latihan terbang simulator FPV (*Liftoff / Velocidrone*) menggunakan Remote Controller fisik.
* **Level 2 (Drone Assembly & Hardware Calibration):**
  * Perakitan fisik rangka drone, pemasangan motor brushless, ESC, Flight Controller (FC), dan VTX.
  * Solder elektronika presisi dan wiring manajemen daya baterai LiPo.
  * Konfigurasi perangkat lunak *Betaflight Configurator*: PID Tuning, kalibrasi gyro, channel radio.
* **Level 3 (Autonomous Drone & Mission Planning):**
  * Drone berotak mikroprosesor (Pixhawk / Raspberry Pi Companion Computer) dengan firmware **ArduPilot / PX4**.
  * Navigasi GPS, Return-to-Home (RTH), Geofencing, dan pembuatan jalur terbang otomatis (*Autonomous Waypoint Mission* via Mission Planner).
  * Computer Vision on Drone: Pelacakan objek darat dari kamera drone secara otomatis.

## 📅 3. Format Pembelajaran & Evaluasi Kelulusan
* **Durasi Program:** 12 Pertemuan per Modul Level (1 Pertemuan = 90 - 120 Menit).
* **Komposisi Waktu:** 20% Review Konsep & Teori, 70% Hands-on Praktik Perakitan/Koding, 10% Demo & Troubleshooting.
* **Tolak Ukur Kelulusan (*Final Project Showcase*):**
  * Setiap akhir level, siswa wajib mempresentasikan 1 proyek nyata di hadapan mentor dan orang tua pada sesi *Widya.X Demo Day*.
