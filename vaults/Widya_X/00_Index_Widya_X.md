## 🎯 3. 4 Pilar Keunggulan Kurikulum Widya.X

1. 🤖 **Robotics (Robotika Terapan):** Mulai dari logika blok dasar, mikrokontroler (Arduino/ESP32), ROS (Robot Operating System), hingga pemrograman robot humanoid canggih (UBTECH Yanshee).
2. 🧠 **Artificial Intelligence (AI):** Computer Vision, Machine Learning terapan, Natural Language Processing, Prompt Engineering, dan integrasi API AI modern.
3. ⚡ **AI Agentic (Autonomous Agents):** Perancangan agent cerdas mandiri (Hermes/OpenClaw/LangChain), multi-agent orchestration, function calling, tool use, dan otomatisasi tugas industri.
4. 🛸 **Drone Engineering & Avionics:** Dasar aerodinamika, perakitan quadcopter/FPV drone, kalibrasi flight controller (Betaflight/ArduPilot), manuver terbang aman, hingga *autonomous waypoint mapping*.
