Tutorial Pemakaian Virtual Tech Worker

Pelajari cara memberikan instruksi tugas agar mendapatkan output kerja maksimal dan terverifikasi.

1 Buka Bot Telegram Resmi

Klik link resmi bot Telegram kami (@Olo_SBT_bot). Tekan tombol /start untuk mengaktifkan kuota 8 Token Free Trial otomatis tanpa biaya.

2 Kirim Perintah Tugas Secara Jelas

Tulis kebutuhan Anda dengan bahasa sehari-hari. Sertakan data angka, konteks bisnis, atau lampirkan file (gambar/tangkapan layar/spreadsheet) jika diperlukan.

Contoh prompt finansial:
"Hitungkan rumus PPN 11% dan biaya fulfillment 5% dari harga jual Rp 1.107.600 beserta rumusnya di Excel."

3 Terima Output & Lakukan Revisi Jika Dibutuhkan

Virtual Tech Worker akan mengeksekusi tugas secara tuntas dan mengirimkan draf dokumen/rumus/kode terverifikasi. Anda dapat meminta penyesuaian atau revisi bertingkat dalam sesi yang sama.
